# Accessibility Guide

All options live in **Settings & Accessibility** (main menu and pause menu)
and persist across sessions.

| Option | Effect |
|---|---|
| Music / Effects / Dialogue volume | Independent audio channels |
| Camera shake | 0–100% screen shake scaling |
| Visual effects intensity | Scales glow/flash/particle strength |
| Reduce flashing | Disables muzzle flash pops, hit strobes, shake randomness |
| Game speed (single player) | 50–100% simulation speed |
| Subtitles + speaker labels + size | Dialogue captions with speaker names, 80–160% size |
| High-contrast enemies | Renders all hostiles in uniform high-contrast red |
| Aim assist (gamepad) | Soft angular snap to line-of-sight targets |
| Hold vs toggle aim | Aim button behaviour |
| Difficulty presets | Rookie / Agent / Kingpin (enemy damage, health, aggression) |
| Remappable controls | Keyboard bindings stored in settings (`bindings` map) |
| Menu navigation | Every screen operable by arrow keys + Enter, mouse, or gamepad focus |
| Touch controls | Automatic landscape twin-stick layout; can be forced on or off |
