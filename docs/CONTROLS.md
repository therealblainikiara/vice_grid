# Controls

**Everything below is rebindable in-game: Settings → Controls.** Each action
holds up to three bindings at once, so keyboard, mouse and controller inputs
coexist rather than competing. Click a binding and press any key, mouse button,
scroll notch or controller button; right-click a binding to clear it; Esc
cancels. "Restore defaults" resets the lot.

A code can only drive one action — binding something already in use silently
removes it from its old action, so one press can never fire two things.

## Defaults

| Action | Keyboard / mouse | Controller |
|---|---|---|
| Move | W A S D **or** arrow keys | Left stick |
| Aim | Mouse | Right stick (aim assist optional) |
| Fire | Left click | RT / R2 |
| Aim / intimidate (hold) | Left Shift — slows movement, pressures morale | LT / L2 |
| Interact — cuff / revive / collect | **Right click** or E (hold) | A / Cross |
| Dodge | Space (RHINO: staggering shove · VIPER: long roll) | B / Circle |
| Melee | F | Y / Triangle |
| Reload | R | X / Square |
| Swap weapon | **Mouse scroll** or Q | LB / L1 |
| Shout "FREEZE" | G — forces an immediate morale check in line of sight | RB / R1 |
| Pause | Esc | Start / Options |

## Playing on a controller

Tick **Settings → Player 1 uses a controller** to drive Player 1 from the pad
(aim moves to the right stick). Player 2 then uses the second pad.

In co-op with Player 1 on keyboard, Player 2 simply presses **Start** on a pad
to drop in at any time — no menu required.

## Arrest flow

1. Pressure a suspect: wound them, drop their friends, aim at them, or shout FREEZE.
2. When they raise their hands (or are incapacitated non-lethally), stand close
   and **hold E** until the cuff ring completes.
3. Cuffed suspects are searched automatically — some carry intel.
4. Beware **fake surrenders**: sly suspects may draw again if you linger.
