# Controls

## Player 1 — keyboard + mouse (remappable; stored in settings)

| Action | Default |
|---|---|
| Move | W A S D |
| Aim | Mouse |
| Fire | Left mouse button |
| Aim / intimidate | Right mouse button (hold; slows movement, pressures morale) |
| Interact — cuff / revive / pick up | E (hold) |
| Dodge | Space (RHINO: staggering shove · VIPER: long roll) |
| Melee | F |
| Reload | R |
| Swap weapon | Q |
| Shout "FREEZE" | G (forces an immediate morale check in line of sight) |
| Pause | Esc |

## Player 2 — gamepad (PlayStation / Xbox layout)

| Action | Binding |
|---|---|
| Move | Left stick |
| Aim | Right stick (aim assist optional) |
| Fire | RT / R2 |
| Aim / intimidate | LT / L2 |
| Interact | A / Cross |
| Dodge | B / Circle |
| Reload | X / Square |
| Melee | Y / Triangle |
| Swap weapon | LB / L1 |
| Shout "FREEZE" | RB / R1 |
| Pause / Join (drop-in) | Start / Options |

## Arrest flow

1. Pressure a suspect: wound them, drop their friends, aim at them, or shout FREEZE.
2. When they raise their hands (or are incapacitated non-lethally), stand close
   and **hold E** until the cuff ring completes.
3. Cuffed suspects are searched automatically — some carry intel.
4. Beware **fake surrenders**: sly suspects may draw again if you linger.
